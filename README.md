# 🚀 DAB (Dab Agency) — Landing Page Oficial

Este repositorio contiene el código fuente de la **Landing Page Oficial de DAB (Dab Agency)**, desarrollado utilizando el framework moderno **Astro** junto con **React** para componentes interactivos y **Tailwind CSS** para los estilos.

## 🛠️ Tecnologías Utilizadas

* **Framework Principal:** [Astro](https://astro.build/) (para un rendimiento óptimo de carga estática)
* **Interactividad y Animaciones:** [React](https://react.dev/) + [Framer Motion](https://www.framer.com/motion/)
* **Estilos:** [Tailwind CSS](https://tailwindcss.com/)
* **Agendamientos Integrados:** Widget Popup de [Calendly](https://calendly.com/)
* **Contacto:** Enlace dinámico directo de WhatsApp API

## 💻 Desarrollo Local

Para los desarrolladores autorizados de DAB, a continuación se detallan los comandos necesarios para la puesta en marcha:

1. **Instalar dependencias:**
   ```sh
   npm install
   ```

2. **Iniciar servidor de desarrollo local (normalmente en `localhost:4321`):**
   ```sh
   npm run dev
   ```

3. **Construir el proyecto para producción:**
   ```sh
   npm run build
   ```

4. **Previsualizar la compilación de producción localmente:**
   ```sh
   npm run preview
   ```
