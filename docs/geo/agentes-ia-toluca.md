## ¿Qué es un agente de IA para un negocio?

Un agente de IA es un sistema de software que realiza tareas cognitivas de forma autónoma —responder mensajes, calificar leads, agendar citas y dar seguimiento— sin intervención humana constante. A diferencia de un chatbot de respuestas fijas, un agente de IA interpretan el contexto, toma decisiones según reglas y se conecta con tus sistemas (WhatsApp, CRM, calendario) para ejecutar acciones reales.
